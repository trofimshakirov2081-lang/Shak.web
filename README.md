# shak.web

Сайты под ключ с админкой для малого бизнеса. Всё работает на Netlify как обычные файлы, без сервера и сборки.

- `index.html` продающая страница
- `brief/` бриф «Соберите свой сайт за 10 минут»
- `demos/` персональные демо для клиентов (инструкция: `demos/КАК-СДЕЛАТЬ-ДЕМО.md`)
- `templates/` шаблоны с админкой
- `tools/` генератор демо и проверка сайтов
- `PLAN.md` план, `CLAUDE.md` памятка для агента

Собрать демо: `node tools/make-demo.mjs demos/_configs/bulochnaya-tani.json`
Проверить сайты: `node tools/check.mjs`
Посмотреть локально: `npx http-server . -p 8080`
