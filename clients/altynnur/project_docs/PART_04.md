# Часть 4. Система управления дизайном

## Назначение
Полноценный конструктор внешнего вида: design tokens, 4 уровня наследования, раздел «Дизайн» в админке, цвета, типографика, Liquid Glass, скругления, карточки, кнопки, фоны, тени, сетка, изображения, иконки, анимации, адаптив, живой предпросмотр, темы, версии, импорт/экспорт, inline-редактор. Каждая настройка даёт реальный эффект на публичном сайте.

## Архитектура дизайн-системы
- Единые CSS-переменные (design tokens), никаких разрозненных значений. Пример базовых токенов: `--color-background #0E0E0E`, `--color-surface #1C1C1C`, `--color-text #F7F3EA`, `--color-muted #B8B1A4`, `--color-accent #C9A45C`, `--font-heading 'Playfair Display'`, `--font-body 'Ysabeau Office'`, `--radius-small 8px / medium 16px / large 24px`, `--glass-opacity 0.12`, `--glass-blur 18px`, `--container-width 1240px`, `--section-spacing 100px`. Реальный набор шире.
- 4 уровня: Глобально → Страница → Блок → Элемент. Приоритет: Элемент > Блок > Страница > Тема. Незаданное наследуется.
- В UI видно, значение собственное или унаследованное; кнопка «Сбросить к наследуемому значению».
- Пример: скругление карточек 20px глобально, 12px в блоке курсов, 4px у одной карточки.
- Одна система токенов на сайт и админку, без второй системы стилей.

## Раздел «Дизайн» в админке
Подразделы: Общий стиль, Цвета, Шрифты, Скругления, Liquid Glass, Карточки и поверхности, Кнопки, Фоны, Тени и границы, Отступы и размеры, Сетка, Анимации, Адаптивность, Готовые темы, Пользовательские темы. Без CSS-кода: пикеры, ползунки, списки, превью у каждой важной настройки.

## Цвета (§4)
- Color picker, HEX, RGB, HSL, прозрачность, свои цвета, свои палитры (создать, дублировать, переименовать, восстановить исходную).
- Роли (независимы): основной фон, доп. фон, фон карточек, фон полей, основной/второстепенный/приглушённый текст, акцент, осн. кнопки, втор. кнопки, границы, разделители, ссылки, активные элементы, успех, предупреждение, ошибка, инфо.
- Цвета компонентов: заголовки, текст, подзаголовки, кнопки, иконки, карточки, их границы, фоны секций, ссылки, плашки, цены, бейджи, формы, навигация, футер.
- Режим «Выбрать элемент» на предпросмотре.
- Проверка контраста с предупреждением «Низкая контрастность. Текст может быть плохо виден на этом фоне» и предложением варианта (не запрет).

## Типографика (§5)
- Исходно: заголовки **Playfair Display**, текст **Ysabeau Office или Finlandica**. Только с кириллицей. **Не Inter.**
- Выбор шрифта для заголовков, текста, кнопок, навигации, цен/цифр. Размер, weight, line-height, letter-spacing.
- Отдельные настройки: H1, H2, H3, H4, основной, второстепенный, подписи, кнопки, навигация, цены, метки.
- Адаптивные размеры через `clamp()` с настраиваемыми min/max. Превью: компьютер, планшет, телефон.
- Загрузка своих шрифтов: только WOFF/WOFF2, проверка файла, защищённое хранилище, никакого исполняемого кода.

## Liquid Glass (§6)
- Эффект стекла в духе современных интерфейсов Apple, а не просто полупрозрачная карточка.
- 11 ползунков с реальными значениями: прозрачность (например 15%), blur (20px), saturation (140%), оттенок, интенсивность оттенка, толщина и прозрачность границы, яркость верхней границы, внутреннее свечение, внешняя тень, отражение, общая сила (70%).
- Включается отдельно: шапка, навигация, выпадающее меню, карточки курсов, карточки преимуществ, кнопки, модалки, формы, уведомления, панели. Для каждого: вкл, выкл, свои параметры, глобальные.
- `backdrop-filter` + `-webkit-backdrop-filter`, fallback для неподдерживающих браузеров, читаемость, без грязного размытия, бережно к мобильной производительности, не на множестве элементов сразу.

## Скругления (§7)
- Общий ползунок «Общее скругление элементов»: 0, 4, 8, 12, 16, 24, 32px, 50% (где уместно).
- Отдельно: карточки курсов, преимуществ, отзывов, кнопки, поля, изображения, галереи, модалки, контейнеры, плашки, блоки цен, навигация. Для иконок скругляется контейнер, а не SVG. Можно для отдельной карточки. Глобальное меняет только наследующие элементы, локальные не сбрасываются.

## Карточки (§8)
Настройки: фон, прозрачность, скругление, граница (толщина, цвет), тень, padding, margin, мин. высота, ширина, выравнивание, hover, анимация появления, Liquid Glass, изображение/фон. Стили: минималистичные, с тонкой границей, с мягкой тенью, стеклянные, контрастные, фото на всю площадь, фото сверху, фото сбоку, без подложки. Глобально + переопределение в блоке.

## Кнопки (§9)
- Настройки: фон, текст, граница, прозрачность, скругление, размер, высота, ширина, padding, шрифт, weight, размер текста, тень, анимация, hover, нажатие, Liquid Glass.
- Типы: основная, второстепенная, контурная, текстовая, прозрачная, стеклянная.
- Состояния: обычное, наведение, нажатие, фокус с клавиатуры, неактивное, загрузка.
- «Записаться» всегда заметна. Золото **#C9A45C** дозированно: основные CTA, цены, важные акценты, активные состояния.

## Фоны (§10)
- Для секций и элементов: цвет, градиент, изображение, видео, полупрозрачный, стекло.
- Градиент: 2+ точки, направление, интенсивность, прозрачность.
- Изображение из медиатеки: позиция, масштаб, повтор, режим (cover, contain и др.), затемнение, blur, оверлей и его прозрачность.
- Видео: размер и оптимизация, автоплей без звука, мобильные, отключение, постер-запасной вариант. Без тяжёлых видео без нужды.

## Тени и границы (§11)
Тень: X, Y, blur, spread, цвет, прозрачность, интенсивность. Пресеты: без, лёгкая, средняя, выраженная, мягкое свечение, внутренняя. Граница: толщина, цвет, прозрачность, тип линии, скругление. Изменения в реальном времени.

## Отступы и сетка (§12)
Ширина контейнера, max/min ширина контента, отступы между секциями, внутренние и внешние отступы, расстояния между карточками и текстом, ширина и число колонок (1, 2, 3, 4, авто), выравнивание. Значения для компьютера, планшета, телефона. Вертикальные отступы каждой секции отдельно. Без горизонтальной прокрутки.

## Изображения (§13)
Соотношение, ширина, высота, скругление, позиция, масштаб, режим, прозрачность, яркость, контраст, насыщенность, blur, фильтр, тень. Форматы: квадрат, портрет, горизонтальный, широкий баннер, вертикальный мобильный. `object-fit`, `object-position`, визуальный выбор видимой области (фокальная точка). Без агрессивных автофильтров, естественные цвета.

## Иконки (§14)
Единый набор SVG. Размер, цвет, толщина линии, фон, скругление и размер контейнера, расположение, анимация. Замена иконки через админку без SVG-кода. Не смешивать стили.

## Анимации (§15)
Общая интенсивность, скорость, длительность, задержка, тип перехода, направление, hover. Варианты: появление, снизу, сбоку, лёгкое увеличение, прозрачность, карточки, кнопки, счётчики, переходы состояний. Сдержанно. `prefers-reduced-motion` отключает или упрощает. Без рывков и сдвигов контента (CLS).

## Оформление секции (§16)
Вкладка «Оформление» у каждой секции: фон, фото, градиент, отступы сверху/снизу, ширина, выравнивание, колонки, скругление, границы, тени, Liquid Glass, анимация, видимость на устройствах. Индивидуальный стиль элементов внутри (например, только карточки в блоке курсов).

## Адаптивный редактор (§17)
Режимы Desktop / Tablet / Mobile с реальной раскладкой. Отдельно: размер текста, отступы, ширина, колонки, выравнивание, положение фото, размер кнопок, видимость. Пример: курсы 3 колонки на ПК, 1 на телефоне. Мобильные правки не ломают десктоп.

## Живой предпросмотр (§18)
Изменение сразу видно без сохранения. Поток: параметр → значение → предпросмотр → черновик → публикация. Разделённый экран (настройки слева, сайт справа), полноэкранный режим, реальные данные сайта, адаптация к размеру.

## Темы (§19)
- Исходная тема «**Ночное золото**»: фон #0E0E0E, доп. фон #1C1C1C, текст #F7F3EA, кремовые поверхности и текстовые акценты #E8D9B5, золото #C9A45C; Playfair Display + Ysabeau Office/Finlandica. Пропорция 60/30/10. Премиально и сдержанно, без блёсток и золотых градиентов.
- Доп. пресеты: светлая, тёмная, минимализм, премиум, мягкий современный, пользовательская. Лучше несколько действительно разных, чем много похожих.
- Действия: выбрать, применить, предпросмотр, изменить, сохранить свою, дублировать, переименовать, удалить свою, вернуть исходную. Тема меняет всё: типографику, карточки, поверхности, границы, тени.

## Сохранение и версии (§20-21)
- Всё в БД, не LocalStorage. Автосохранение черновика, ручное сохранение, публикация, undo, redo, история, восстановление версии, возврат к исходной теме, подтверждение опасных действий.
- Экспорт темы в JSON и импорт с проверкой структуры и диапазонов; меняются только разрешённые параметры; никакого CSS/JS-кода.

## Inline Editor (§22)
Кнопка «Редактировать сайт» в админке → привычный сайт с рамками при наведении. Клик: заголовок → текст и типографика; фото → выбор и отображение; кнопка → текст, ссылка, цвет, размер; карточка → её настройки; фон секции → фон. Подсказки о выбранном элементе. Работа в черновике, только после авторизации, посетители инструментов не видят.

## UI редактора дизайна (§23)
Ползунок: название, значение, min/max, ручной ввод, сброс. Цвет: образец, код, превью. Скругления: визуальные образцы. Тени: примеры карточек. Glass: демо-элемент. Вкладки и раскрывающиеся группы.

## Безопасность и производительность (§24)
Никакого произвольного CSS в страницу, никакого JS через поля. Валидация чисел, цветов, URL, диапазонов (без отрицательных и огромных размеров). Только CSS-переменные и контролируемые классы. Быстрая загрузка настроек, не грузить неиспользуемое, без мерцания при смене дизайна.

## Исходный дизайн (§25)
Сайт сразу выглядит профессионально: премиальная типографика, иерархия, воздух, выразительные фото, сдержанное золото, современные карточки, продуманная сетка, плавные анимации, качественная мобильная версия. Не шаблонный лендинг с одинаковыми карточками: секции с разной композицией.

## Критерии проверки (§26, 28 сценариев)
Меняются на сайте: основной цвет; цвет текста отдельно от фона; шрифт заголовков; шрифт текста; размеры заголовков; общее скругление карточек; скругление одной карточки; Liquid Glass вкл и настройка; прозрачность и blur стекла; тени и границы; фон секции; ширина контейнера; отступы между секциями; число колонок; кнопки; анимации; мобильная версия отдельно. Плюс: всё в предпросмотре, черновик, публикация, сохранение после перезагрузки, undo, восстановление версии, своя тема, готовая тема, inline-редактирование, доступ только админу, посетитель не видит инструментов.

## Отчёт после реализации (§27)
Проверить совместимость с публичной частью и админкой, не ломать структуру и порядок блоков. Сообщить: реализованные функции, таблицы/поля БД, компоненты, протестированное, нереализованное, действия для запуска.
