# АлтынНур: архитектура страниц v2

Превью на GitHub Pages: `sites/altynnur/`. Адреса с завершающим `/` (папка с `index.html`). Страницы курсов собираются из данных: новый курс в данных означает новую страницу (в превью страницы создаёт `sites/altynnur/tools/pages.mjs`, в рабочей версии маршрут `/courses/{slug}` отдаёт сервер).

| URL | Страница | Содержание | Откуда пришло |
|---|---|---|---|
| `/` | Главная | hero; манифест; 3 направления; лента избранных курсов; «профессия в деталях»; преподаватель кратко + преимущества; короткая запись | сжато из v1 |
| `/courses/` | Курсы | вступление; фильтр по направлениям (`?cat=`); курсы разворотами; «не знаете, что выбрать?» → подбор | каталог с главной |
| `/courses/{slug}/` | Курс | hero (3 варианта); цена; что изучите; пара фото; параметры (только заполненные); наборы; частые вопросы; запись; другие курсы | была `course.html?c=` |
| `/about/` | Об академии | название и смысл; подход (тексты ТЗ); атмосфера коллажем; преподаватель (поля заполнит Айгуль) | преподаватель с главной |
| `/works/` | Работы | фильтр; галерея с просмотром; пока пусто: честная заглушка + иллюстрации с пометкой | новый |
| `/training/` | Как проходит обучение | 4 этапа; что известно (очно, Туймазы); подбор курса (квиз) | этапы и квиз с главной |
| `/faq/` | Вопросы | 10 вопросов аккордеоном | FAQ с главной |
| `/contacts/` | Контакты | телефон, WhatsApp, VK, город; адрес и карта появятся позже; форма | контакты с главной |

**Не создаём:** отдельную страницу отзывов (настоящих отзывов пока нет, блок появится на `/works/` и главной, когда они будут).

## Навигация
- **Шапка:** Курсы, Обучение, Работы, Об академии, Контакты + кнопка «Записаться» (открывает форму). Логотип ведёт на главную. Активный пункт подсвечен.
- **Мобильное меню** на весь экран, крупные пункты, внизу телефон и WhatsApp.
- **Крошки** на внутренних страницах: Главная / Курсы / Название.
- **Переходы:**
  - главная → направление → `/courses/?cat=…` (фильтр выставлен);
  - главная → курс в ленте → страница курса;
  - курс → «Записаться» → форма с подставленным курсом;
  - курс → «Все курсы» и «Другие курсы»;
  - обучение → подбор → результат → страница курса или заявка;
  - работы и об академии → курсы → запись.
- **Подвал:** все страницы, политика, контакты.
- Подбор курса (квиз) открывается кнопкой «Подобрать курс» с любой страницы, сам блок живёт на `/training/`.

## SEO в превью
- У каждой страницы свой `<title>` и description.
- Канонический адрес на будущий домен поставим при запуске.
- `robots noindex` на превью, чтобы черновик не попал в поиск.
- Sitemap, 404 с кодом и Schema.org сделает сервер в рабочей версии (см. OPEN_QUESTIONS №2). В превью JSON-LD организации есть на главной.

## Данные (совместимость с будущей CMS)
- **`assets/data.js`:** организация, навигация, страницы, курсы (slug, layout, фото, темы), направления, тексты. Каждый ключ соответствует будущей таблице из MASTER_REQUIREMENTS §2.
- **Блоки главной** заданы массивом `blocks` с порядком и видимостью, как в v1.
