ЧАСТЬ 9. АНИМАЦИИ, ИНТЕРАКТИВНОСТЬ, ВИЗУАЛЬНЫЕ ЭФФЕКТЫ И ПРЕМИАЛЬНЫЙ ПОЛЬЗОВАТЕЛЬСКИЙ ОПЫТ

1. Главная задача

Создай для учебного центра «АлтынНур» современный, визуально выразительный сайт премиального уровня.

Сайт не должен выглядеть как стандартный шаблон образовательной платформы или типовой лендинг, собранный из одинаковых карточек.

Нужно создать ощущение:

* Профессиональной школы.
* Высокого качества обучения.
* Внимания к деталям.
* Эстетики индустрии красоты.
* Доверия к преподавателю.
* Современного подхода к обучению.
* Серьезного отношения к будущей профессии учениц.

Визуальная концепция: сдержанная роскошь, современный editorial-дизайн, эстетика beauty-журналов, аккуратная типографика, выразительная фотография, продуманная композиция.

Не превращай сайт в кричащий магазин косметики.

Не используй повсеместно золотые градиенты, блестки, короны, декоративные завитки и другие банальные элементы.

Задача - сделать дорого, спокойно, современно и профессионально.

2. Визуальное направление

Используй уже определенную концепцию «Ночное золото».

Основные цвета:

* #0E0E0E - основной темный фон.
* #1C1C1C - дополнительные темные поверхности.
* #F7F3EA - светлый текст и светлые секции.
* #E8D9B5 - вторичные кремовые оттенки.
* #C9A45C - золотой акцент.

Соблюдай распределение цветов:

* 60% - основной фон.
* 30% - дополнительные поверхности и светлые секции.
* 10% - акценты.

Золотой цвет не должен использоваться повсюду.

Он нужен для:

* Основных CTA.
* Цен.
* Активных состояний.
* Небольших декоративных деталей.
* Важных акцентов.

Предусмотри возможность изменения всей палитры через админку.

3. Визуальная композиция

Не собирай всю страницу по одному принципу.

Чередуй разные типы композиций:

* Полноэкранный Hero.
* Асимметричные секции.
* Фотографии с текстовыми колонками.
* Большие типографические заголовки.
* Карточки разного размера.
* Горизонтальные ленты.
* Сетки с фотографиями.
* Выделенные цитаты.
* Контрастные светлые секции.
* Большие визуальные паузы.

Не делай все секции одинаковыми по высоте.

Не используй одинаковые карточки в каждом блоке.

У каждого раздела должна быть собственная визуальная задача.

Продумай визуальный ритм всей страницы.

4. Hero: первое впечатление

Первый экран должен сразу создавать правильное впечатление.

Предусмотри:

* Сильный заголовок.
* Короткий подзаголовок.
* Основную кнопку записи.
* Вторичное действие для просмотра курсов.
* Выразительную фотографию или композицию из нескольких изображений.
* Небольшие информационные акценты.

Не перегружай Hero текстом.

Не используй стандартную конструкцию «заголовок слева, случайная фотография справа», если есть возможность сделать более выразительную композицию.

Рассмотри:

* Большую фотографию на весь экран.
* Асимметричное расположение текста.
* Текст поверх фотографии с корректным контрастом.
* Слои изображения.
* Небольшую анимированную типографику.
* Аккуратные декоративные линии.
* Мягкий градиент для читаемости.

Все элементы Hero должны редактироваться через админку.

Если настоящих фотографий нет, не генерируй ложные фотографии преподавателя, учениц или реальных работ.

Используй временные нейтральные заглушки, которые легко заменить.

5. Типографика

Основной шрифт заголовков: Playfair Display.

Для основного текста используй Ysabeau Office или Finlandica с полноценной поддержкой кириллицы.

Не используй Inter как основной шрифт.

Создай четкую типографическую систему:

* Hero Heading.
* H1.
* H2.
* H3.
* Body Large.
* Body Regular.
* Body Small.
* Caption.
* Label.
* Button.
* Price.

Продумай:

* Размеры.
* Межстрочные интервалы.
* Межбуквенные интервалы.
* Насыщенность.
* Контраст.
* Переносы строк.
* Ограничение ширины текстовых блоков.

Не используй слишком мелкий текст.

Заголовки должны выглядеть выразительно, но оставаться читаемыми на мобильных устройствах.

6. Анимационная система

Создай единую систему анимаций.

Анимации должны быть частью дизайна, а не случайными эффектами.

Используй разные типы движения в зависимости от задачи.

6.1. Появление элементов

Предусмотри:

* Fade In.
* Fade Up.
* Fade Down.
* Slide In.
* Scale In.
* Blur In.
* Stagger Reveal.

Элементы могут появляться при прокрутке.

Но не анимируй абсолютно каждый элемент.

Используй анимацию там, где она улучшает восприятие.

6.2. Появление заголовков

Для крупных заголовков можно использовать:

* Появление по строкам.
* Плавное проявление.
* Легкое смещение.
* Последовательное появление слов.

Не делай анимацию слишком медленной.

Не заставляй пользователя ждать, пока появится важный текст.

6.3. Анимации фотографий

Используй аккуратные эффекты:

* Плавное проявление.
* Небольшое увеличение при наведении.
* Мягкое смещение.
* Эффект маски при появлении.
* Плавное изменение кадрирования.

Не применяй сильное увеличение, которое обрезает важные детали фотографий.

6.4. Анимации карточек

Карточки курсов могут:

* Немного приподниматься при наведении.
* Плавно менять фон.
* Показывать дополнительные сведения.
* Подсвечивать кнопку.
* Иметь мягкую тень.

Не делай резких прыжков и чрезмерных вращений.

На мобильных устройствах hover-эффекты должны заменяться подходящими состояниями нажатия.

7. Премиальные интерактивные эффекты

Предусмотри несколько выразительных эффектов.

Выбирай их по необходимости, а не используй все одновременно.

7.1. Плавная прокрутка

Реализуй плавную прокрутку к секциям при переходах по якорным ссылкам.

Учитывай высоту шапки.

Не ломай стандартную навигацию браузера.

Уважай prefers-reduced-motion.

7.2. Параллакс

Для отдельных крупных фотографий можно использовать очень мягкий параллакс.

Движение должно быть минимальным.

Не допускай ухудшения производительности на телефонах.

Добавь возможность отключить параллакс через админку.

7.3. Magnetic Buttons

Для десктопа можно предусмотреть деликатный эффект магнитного движения кнопки при приближении курсора.

Эффект должен быть очень слабым.

На сенсорных устройствах он отключается.

7.4. Custom Cursor

Допускается разработка кастомного курсора для отдельных интерактивных элементов.

Но:

* Не заменяй стандартный курсор повсеместно.
* Не ухудшай доступность.
* Не используй эффект на мобильных устройствах.
* Не создавай лишнюю нагрузку.

Если кастомный курсор не улучшает интерфейс, не используй его.

7.5. Liquid Glass

Используй концепцию Liquid Glass только в подходящих элементах:

* Плавающие панели.
* Небольшие информационные элементы.
* Навигационные поверхности.
* Всплывающие окна.
* Отдельные кнопки.

Не превращай весь сайт в прозрачное стекло.

Эффект должен быть сдержанным.

Параметры регулируются через админку:

* Прозрачность.
* Blur.
* Насыщенность.
* Цветовой оттенок.
* Граница.
* Подсветка.
* Тень.

Всегда проверяй читаемость текста.

8. Интерактивная навигация

Сделай навигацию удобной и визуально качественной.

Предусмотри:

* Плавное раскрытие мобильного меню.
* Аккуратное активное состояние.
* Hover-состояния.
* Подсветку текущего раздела.
* Плавный переход к нужной секции.
* Корректную работу клавиатуры.

На мобильных устройствах меню должно открываться быстро и не перекрывать важные элементы некорректным образом.

Кнопка «Записаться» должна быть заметной, но не навязчивой.

9. Интерактивный каталог курсов

Каталог должен ощущаться как полноценный современный интерфейс.

Предусмотри:

* Фильтрацию.
* Категории.
* Поиск.
* Сортировку.
* Переключение вида карточек, если это оправдано дизайном.
* Плавное обновление результатов.
* Состояние отсутствия результатов.

Карточки курсов должны содержать:

* Фотографию.
* Название.
* Краткое описание.
* Цену, если она подтверждена.
* Длительность, если она известна.
* Уровень подготовки, если он известен.
* Кнопку просмотра программы.

При наведении на карточку можно использовать дополнительное изображение или визуальное состояние.

Не загружай все фотографии высокого разрешения сразу.

10. Квиз с интерактивным сценарием

Квиз должен выглядеть как современный пошаговый интерфейс.

Предусмотри:

* Анимированный переход между вопросами.
* Индикатор прогресса.
* Понятные варианты ответов.
* Возможность вернуться назад.
* Плавное отображение результата.
* Рекомендацию подходящего курса.
* Переход к заявке.

Не используй резкие переходы.

Не заставляй пользователя начинать заново при случайном возвращении на предыдущий вопрос.

Все вопросы, варианты и логика должны редактироваться через админку.

11. Галерея работ

Галерея должна стать одним из визуальных центров сайта.

Предусмотри:

* Masonry или асимметричную сетку.
* Большие фотографии.
* Разные пропорции изображений.
* Просмотр в полноэкранном режиме.
* Плавное открытие.
* Переключение между изображениями.
* Подписи, если они нужны.
* Фильтрацию по направлениям.

Не превращай галерею в обычную сетку из одинаковых квадратов.

Фотографии должны отображаться в хорошем качестве, но загружаться оптимизированно.

Для реальных работ и фотографий учеников учитывай согласие на публикацию.

12. Слайдер до и после

Реализуй интерактивный Before / After Slider.

Пользователь должен иметь возможность двигать разделитель между двумя изображениями.

Требования:

* Плавное управление.
* Работа пальцем на телефоне.
* Работа мышью.
* Управление клавиатурой.
* Правильное масштабирование.
* Сохранение общего кадрирования.
* Подписи «До» и «После».

Если реальных пар фотографий нет, не создавай фальшивые результаты.

Блок должен скрываться, если в админке нет опубликованных материалов.

13. Интерактивные FAQ

Реализуй раскрывающиеся вопросы.

Предусмотри:

* Плавное раскрытие.
* Закрытие.
* Аккуратные иконки.
* Доступность с клавиатуры.
* Корректную работу на телефоне.

Не открывай все вопросы одновременно без необходимости.

Содержимое полностью редактируется через CMS.

14. Формы и обратная связь

Формы должны иметь продуманные состояния.

Предусмотри:

* Обычное состояние.
* Фокус.
* Ошибку.
* Успешную отправку.
* Загрузку.
* Недоступность отправки.
* Повторную отправку при ошибке.

Добавь мягкую анимацию подтверждения заявки.

Не используй раздражающие всплывающие окна.

После успешной отправки покажи понятное сообщение и следующий шаг.

15. Микровзаимодействия

Добавь качественные мелкие детали:

* Изменение состояния кнопки.
* Анимированная стрелка.
* Плавная подсветка ссылок.
* Состояние загрузки.
* Появление подсказок.
* Плавное открытие селектов.
* Небольшие изменения цвета.
* Аккуратные индикаторы прогресса.

Микровзаимодействия должны создавать ощущение качественного продукта.

Не добавляй эффекты только ради эффектов.

16. Видео и визуальный контент

Предусмотри возможность использовать короткие видео в:

* Hero.
* Блоке преподавателя.
* Галерее.
* Презентации обучения.
* Карточках отдельных направлений.

Видео должно:

* Быть оптимизированным.
* Не запускаться со звуком автоматически.
* Не мешать загрузке основного контента.
* Иметь постер.
* Корректно отображаться на мобильных устройствах.

Не загружай тяжелые видео без необходимости.

Не используй видео как обязательный элемент каждого блока.

17. Адаптивные анимации

Разработай отдельное поведение анимаций для:

* Desktop.
* Tablet.
* Mobile.

На телефонах:

* Уменьши сложность эффектов.
* Отключи тяжелый параллакс.
* Не используй hover-зависимые сценарии.
* Не перегружай процессор.
* Сохраняй плавность.
* Не блокируй прокрутку.

Если устройство имеет ограниченную производительность, эффекты должны деградировать корректно.

18. Доступность

Визуальная красота не должна ухудшать доступность.

Обязательно:

* Поддерживай клавиатурную навигацию.
* Сохраняй видимый focus.
* Используй корректные aria-label.
* Проверяй контраст.
* Поддерживай prefers-reduced-motion.
* Не передавай информацию только цветом.
* Делай интерактивные элементы понятными.
* Обеспечь читаемость при масштабировании.

Не создавай анимации, которые могут вызывать дискомфорт.

19. Производительность анимаций

Предпочитай анимации transform и opacity.

Не запускай постоянные тяжелые вычисления при прокрутке.

Используй Intersection Observer там, где это уместно.

Избегай большого количества одновременно работающих анимаций.

Не создавай бесконечные анимации для декоративных элементов без необходимости.

Проверь:

* FPS на обычном смартфоне.
* Время загрузки.
* Плавность прокрутки.
* Потребление памяти.
* Корректность отключения эффектов.

20. Настройки анимаций в админке

Добавь отдельный раздел «Анимации».

Владелица должна иметь возможность:

* Включить или выключить анимации.
* Выбрать общий уровень интенсивности.
* Настроить скорость.
* Выбрать тип появления блоков.
* Отключить параллакс.
* Настроить эффекты карточек.
* Настроить анимации кнопок.
* Выбрать эффекты фотографий.
* Настроить задержки.
* Настроить эффекты при прокрутке.

Добавь несколько готовых пресетов:

1. Minimal: почти незаметные анимации.
2. Elegant: плавные и сдержанные.
3. Editorial: выразительные появления крупных элементов.
4. Dynamic: более активные взаимодействия.

Начальный пресет для «АлтынНур» - Elegant.

Настройки должны сохраняться в базе данных и влиять на публичную часть.

21. Визуальная целостность

Не допускай, чтобы сайт выглядел как набор компонентов из разных шаблонов.

У всех элементов должна быть общая дизайн-система:

* Единая типографика.
* Единая система отступов.
* Единые радиусы.
* Согласованные цвета.
* Единый стиль кнопок.
* Согласованные состояния.
* Единая логика анимаций.
* Последовательный стиль иконок.

При этом отдельные блоки могут иметь собственную композицию.

Не делай все элементы одинаковыми только ради единообразия.

22. Визуальный контроль качества

Перед завершением сравни сайт с современными качественными сайтами образовательных и beauty-брендов.

Оцени:

* Первое впечатление.
* Визуальную иерархию.
* Качество композиции.
* Типографику.
* Фотографии.
* Анимации.
* Читаемость.
* Мобильную версию.
* Удобство взаимодействия.

Не копируй чужой сайт.

Используй референсы только для понимания уровня качества.

Не делай вывод о качестве только по тому, что сайт красиво выглядит на одном скриншоте.

Проверь реальные сценарии использования.

23. Критерии готовности

Считай эту часть реализованной, когда:

1. Сайт имеет цельную визуальную концепцию.
2. Используется палитра «Ночное золото».
3. Есть продуманная типографика.
4. Hero создает сильное первое впечатление.
5. Секции имеют разнообразную композицию.
6. Есть единая система анимаций.
7. Появление элементов работает плавно.
8. Карточки имеют качественные интерактивные состояния.
9. Навигация работает корректно.
10. Каталог курсов интерактивен.
11. Квиз имеет плавные переходы.
12. Галерея имеет удобный просмотр.
