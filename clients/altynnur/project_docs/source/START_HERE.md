3. ЭКОНОМИЯ КОНТЕКСТА И ТОКЕНОВ

Это один из главных приоритетов всей работы.

Соблюдай следующие правила:

3.1. Не перечитывай уже изученные документы

Если часть уже обработана и её конспект сохранён, используй конспект.

Не открывай исходный файл повторно без необходимости.

Возвращайся к оригиналу только если:

* В конспекте недостаточно информации.
* Обнаружено противоречие.
* Необходимо проверить точную формулировку.
* Для реализации требуется конкретная деталь, которую нельзя восстановить из конспекта.

3.2. Не загружай все документы в контекст

Не используй команды, которые одновременно выводят содержимое всех 11 документов.

Не копируй весь текст ТЗ в один файл.

Не создавай огромные сообщения с полным повторением требований.

3.3. Работай с короткими конспектами

В дальнейшем используй:

* INDEX.md для навигации.
* PROGRESS.md для понимания текущего этапа.
* MASTER_REQUIREMENTS.md для общих требований.
* PART_XX.md для конкретных деталей.
* OPEN_QUESTIONS.md для неразрешённых вопросов.

3.4. Не повторяй анализ

Если ты уже определил, как должна работать конкретная функция, не анализируй её повторно без новой причины.

Если требование повторяется в нескольких частях, объедини его в одно требование и укажи ссылки на связанные документы.

3.5. Не создавай лишние отчёты

Не пиши длинные объяснения пользователю.

После каждого этапа достаточно короткого сообщения:

* Какой документ обработан.
* Какой конспект создан.
* Есть ли критические противоречия.
* Какой следующий документ ожидает обработки.
