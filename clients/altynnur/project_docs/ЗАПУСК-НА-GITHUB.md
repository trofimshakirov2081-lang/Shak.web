# АлтынНур: запуск на GitHub Pages (бесплатный вариант)

Айгуль выбрала 16.11 простой вариант: без платного хостинга, платит только за домен altynnur.ru.
Тексты, цены, фото и даты она меняет в админке (`/admin/`), кнопка «Опубликовать» сохраняет всё в GitHub,
сайт обновляется примерно за минуту. Заявки уходят ей в WhatsApp, в админке не хранятся.

## Что сделать Трофиму (один раз, минут 15)
1. GitHub: создать **публичный** репозиторий `altynnur` (бесплатные Pages только у публичных).
2. Выложить в него содержимое `sites/altynnur/` (корень репозитория = корень сайта). Папка `api/` не нужна.
3. Settings, Pages: Source "Deploy from a branch", ветка `main`, папка `/`.
4. Ключ: Settings (профиль), Developer settings, Fine-grained tokens, Generate:
   доступ только к репозиторию `altynnur`, Permissions: Contents **Read and write**, срок: максимальный (год), поставить напоминание продлить.
5. Пароль для Айгуль: не короче 12 символов (config.js лежит в открытом репозитории, ключ в нём зашифрован этим паролем).
6. `node tools/gh-key.mjs <логин> altynnur main <ключ> <пароль>` в папке сайта, загрузить получившийся `admin/config.js` в репозиторий.
   Ключ и пароль никуда больше не сохранять, пароль передать Айгуль лично.
7. Домен altynnur.ru (около 200-300 ₽ в год, оформить на Айгуль): в DNS четыре A-записи
   185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME `www` на `<логин>.github.io`.
   В репозитории файл `CNAME` с текстом `altynnur.ru`, в Settings, Pages указать домен и включить HTTPS.
8. Перед запуском в админке, раздел «Оформление», выключить «Режим черновика».

## Как устроено
- `admin/gh.js`: вход по паролю (расшифровка ключа в браузере), загрузка `assets/data.js`, публикация одним коммитом
  (data.js + страницы курсов из `assets/pages-lib.js`), фото уменьшаются в браузере до 640/1280/1600 px.
- Черновик хранится на устройстве, где его правили, до публикации.
- История версий = история коммитов `assets/data.js`, «Вернуть» кладёт старую версию в черновик.
- Без `admin/config.js` админка работает как раньше: PHP-сервер (Beget), иначе пробный режим.
- Проверено на поддельном GitHub API: вход, неверный пароль, цена, фото, публикация, страница курса, версии, смена пароля.
