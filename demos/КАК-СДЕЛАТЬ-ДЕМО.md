# Как сделать персональное демо для клиента

Демо это копия шаблона с названием, цветами, логотипом и товарами клиента. Шаблон в `templates/` при этом не меняется.

## Самый быстрый способ

Написать агенту в Claude Code:

```
/demo Кофейня Зерно, кофейня, зелёный и бежевый, латте 1500, капучино 1300, круассан 900, чизкейк 1800
```

Агент сам создаст файл настроек, соберёт демо, проверит его на телефоне и пришлёт ссылку.

## Вручную за 3 шага

**1. Скопируйте пример настроек**

`demos/_configs/bulochnaya-tani.json` → `demos/_configs/kofeynya-zerno.json`

**2. Поменяйте в нём главное**

```json
{
  "name": "Кофейня Зерно",
  "niche": "кофейня",
  "city": "Астана",
  "colors": ["зелёный", "бежевый"],
  "logo": "files/zerno-logo.png",
  "items": [
    { "name": "Латте", "price": 1500 },
    { "name": "Капучино", "price": 1300, "desc": "Двойной эспрессо и молоко" },
    { "name": "Круассан", "price": 900 }
  ]
}
```

Обязательные поля только три: `name`, `niche`, `items` (у каждого товара название и цена). Остальное генератор возьмёт из готовых текстов для ниши.

**3. Соберите**

```
node tools/make-demo.mjs demos/_configs/kofeynya-zerno.json
```

Готово: папка `demos/kofeynya-zerno/`, после публикации ссылка будет `ваш-сайт.netlify.app/demos/kofeynya-zerno/`. Демо сразу появится в витрине `demos/`.

Команда без файла (`node tools/make-demo.mjs`) пересобирает все демо разом, например после правки шаблона.

## Все настройки

| Поле | Что это | Пример |
|---|---|---|
| `name` | Название бизнеса | `"Булочная Тани"` |
| `niche` | Ниша: кондитерская, пекарня, кофейня, цветы, салон, брови, студия, йога и т.п. | `"кондитерская"` |
| `items` | 3-6 товаров или услуг: `name`, `price`, по желанию `desc`, `emoji`, `photo`, `tag` | см. пример |
| `colors` | 1-4 цвета словами или HEX: основной, акцент, фон, текст. Можно один, остальные подберутся | `["шоколадный", "#F2C14E"]` |
| `logo` | Файл логотипа (положите в `demos/_configs/files/`) или ссылка | `"files/logo.svg"` |
| `city` | Город | `"Алматы"` |
| `tagline` | Подпись под названием | `"Семейная булочная"` |
| `hero` | Заголовок и текст первого экрана: `title`, `text`, `cta` | |
| `about` | Текст блока «О нас» | |
| `features` | 3 преимущества: `icon`, `title`, `text` | |
| `fonts` | Шрифты Google: `head`, `body` | `{"head": "Lora"}` |
| `currency` | Валюта, по умолчанию ₸ | `"₽"` |
| `contacts` | `phone`, `whatsapp`, `telegram`, `instagram`, `address`, `hours` | |
| `pin` | PIN админки, по умолчанию 1234 | `"2580"` |
| `slug` | Имя папки, по умолчанию из названия латиницей | `"tani"` |
| `demoBanner` | `false`, чтобы скрыть полоску «Демо от shak.web» | |

Цвета словами: красный, бордовый, розовый, пудровый, пыльная роза, малиновый, оранжевый, персиковый, терракотовый, коралловый, жёлтый, горчичный, золотой, зелёный, оливковый, мятный, изумрудный, шалфей, голубой, синий, тёмно-синий, бирюзовый, фиолетовый, лавандовый, сиреневый, коричневый, шоколадный, кофейный, карамельный, бежевый, молочный, кремовый, ванильный, белый, серый, графитовый, чёрный.

## Что отправить клиенту

1. Ссылку на демо: «Сделала набросок сайта для вас, посмотрите с телефона».
2. Ссылку на админку (`.../admin.html`) и PIN: «Попробуйте сами поменять цену».
3. Через день спросить, что поменять бы в первую очередь.

## Как работает админка

- Правки в админке сохраняются в браузере и сразу видны на сайте этому человеку.
- Чтобы правку увидели все, в админке есть «Ещё → Скачать data.js». Файл кладётся в папку сайта вместо старого.
- Для боевых сайтов, где владелец часто меняет цены, лучше подключить общее хранилище (см. PLAN.md, задача про админку).
