# Контроль качества перед сдачей

Читать: перед словом «готово», перед показом клиенту, перед выкладкой.

## Обязательно
- Смотреть результат глазами: скриншоты с телефона 390px (и 375, 430 для шапки и кнопок), а не только код. Перед «готово» обязательно.
- Все страницы: нет ошибок в консоли, битых файлов (404), горизонтальной прокрутки.
- Все кнопки и формы работают по-настоящему; форма проверяет поля; промокод, калькулятор, запись дают верный результат.
- Текст поверх фото читается и не закрывает лица; нет пустых мест; разнородные фото в одной гамме.
- Меню закрывается нажатием в любое место, нажатие мимо пунктов не срабатывает на элементах под меню; значок меню корректный.
- Нет «заглушек» для заказчика на сайте (пометки «иллюстрация», «предварительно», «утвердим»), если их просили убрать.
- Скорость: размеры фото, ленивая загрузка, видео только при появлении.
- SEO: title, description, Open Graph, robots (noindex на черновике, index при запуске), карта сайта.
- Админка: пункты из `admin-panel.md` раздел «Обязательная проверка логики», тест «изменил, перезагрузил, сохранилось» по каждому способу изменения.
- Для шаблонов: `node tools/make-demo.mjs` и `node tools/check.mjs` по всем демо.

## Порядок
1. Автотест (Playwright): страницы, ошибки, 404, переполнение.
2. Скриншоты ключевых экранов на телефоне, разбор глазами.
3. Сценарии клиента: найти курс, сравнить, записаться, написать.
4. Сценарии владельца: изменить в админке, посмотреть, опубликовать.
5. Финальная полировка. Первая рабочая версия не финал.
