# Разработка сайтов: архитектура и правила

Читать: при создании сайта или демо, правках шаблонов, сборке, выкладке. Для дизайна дополнительно `premium-design.md`, для админки `admin-panel.md`.

## Технологии и ограничения
- Статика без сборки: HTML, CSS, JS. Хостинг: GitHub Pages (основной, без лимитов), Netlify только для старых демо (кредиты кончились, туда не выкладываем).
- Без своих серверов и баз. Сторонние сервисы можно, если работают из браузера.
- Исключение по выбору заказчика: Beget с PHP и MySQL (emirald.ru, PHP-вариант AltynNur). Для бесплатного варианта: админка сохраняет данные в GitHub (`sites/altynnur/admin/gh.js`).
- Шаблоны и админки не ломать: правки для клиентов только в копиях (`demos/`, `sites/`). Изменения шаблона проверять на всех демо (`node tools/make-demo.mjs` и `node tools/check.mjs`).
- Работу сохранять в отдельной ветке, не в `main`.

## Где что лежит
| Путь | Что это |
|---|---|
| `index.html`, `landing.css` | Продающая страница shak.web |
| `brief/index.html` | Бриф (один файл): `CONFIG` (бот, контакты) и `PRICE`. Оригинал без правок: `templates/originals/brief/` |
| `brief-v2/` | Черновой бриф агента, не используется |
| `templates/originals/` | Настоящие шаблоны (Эмирэлд, Malli, Summer). **Не править** |
| `templates/konditerskaya/` | Базовый шаблон с админкой (`admin.html`, PIN в `data.js`). Не править для клиентов |
| `tools/make-demo.mjs`, `tools/niches.json` | Генератор демо и тексты ниш |
| `demos/_configs/*.json`, `demos/_configs/files/` | Настройки демо, картинки |
| `demos/<slug>/` | Собранные демо (генерируются, руками не править). Инструкция `demos/КАК-СДЕЛАТЬ-ДЕМО.md` |
| `sites/<проект>/` | Сайты клиентов и концепты (публикуются на github.io) |
| `clients/<проект>/` | Материалы и документы клиентов (не публикуются) |
| `raboty/` | Портфолио, видео лучших демо. `raboty/videos.json`, запись `node tools/record-video.cjs raboty/videos.json` при http-server на 8080 |
| `tz/` | Страница «полный брендбук и ТЗ» |
| `backend/shakweb-bot/` | Бот @shakweb_bot (Google Apps Script) |
| `tools/check.mjs` | Проверка всех сайтов, отчёт `reports/check-report.md` |
| `tools/video/` | Инструменты роликов |
| `PLAN.md`, `ЦЕНЫ.md`, `ДИЗАЙНЫ.md`, `ПАМЯТКА.md` | План, цены, журнал дизайнов, текущее состояние |

## Команды
- `node tools/make-demo.mjs demos/_configs/<файл>.json` одно демо; без аргумента все.
- `node tools/check.mjs` проверка (`--external` ещё внешние ссылки).
- `npx http-server . -p 8080 -c-1` смотреть локально.
- `sh tools/publish-gh.sh` выкладка сайта на GitHub Pages.

## Структура сайта
Секции под задачи бизнеса, не ради количества: первый экран, услуги или каталог с ценами, как проходит работа, галерея, специалисты, отзывы, FAQ, онлайн-запись или форма, контакты с картой, а при пользе: акции, наборы с местами, калькулятор, сравнение тарифов. Каждая кнопка работает по-настоящему, никакой имитации.

## Технические требования
- Семантическая разметка, доступность (alt, aria, фокус, контраст), обработка ошибок форм.
- SEO: title, description, Open Graph, schema.org, robots (noindex на черновиках), sitemap при запуске.
- Скорость: webp в размерах 640/1280/1600, ленивая загрузка, видео грузить только при появлении на экране.
- Мобильная версия как отдельная композиция: без горизонтальной прокрутки, крупные кнопки, удобно одной рукой.
- Ничего не закреплять у нижнего края экрана (position: fixed внизу): Safari на iPhone заливает свою панель цветом. Призыв к действию в шапке.
- Учитывать prefers-reduced-motion.
- Персональные данные: согласие в формах, политика, данные в России там, где это требуется.
