# Проекты клиентов

Здесь у каждого клиента своя папка с локальным `CLAUDE.md`: бизнес, аудитория, дизайн-концепция, функции, ограничения, админка, контакты, статус. Требования одного клиента не переносить в другие проекты.

Код и материалы лежат в исторических местах и не переносятся (на них завязаны выкладка и адреса сайтов):
- код сайта: `sites/<проект>/` (публикуется на github.io);
- материалы и документы: `clients/<проект>/` (не публикуются);
- демо для лидов: `demos/<slug>/`, настройки `demos/_configs/`.
