# Идеи собственного IT-продукта

По одной идее на файл, по шаблону из `instructions/it-product-research.md`: суть, проблема, покупатели, как решают сейчас, недостатки конкурентов, преимущество, монетизация, сложность, стоимость запуска, проверка спроса, риски, масштабирование. Каждое утверждение помечать «подтверждено (источник)» или «гипотеза».
