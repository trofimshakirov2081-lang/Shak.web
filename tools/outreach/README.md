# Инструменты рассылки (пачка №6)

Списки контактов в репозиторий не кладём: он публичный. Если временная папка пропала, контакты собираются заново.

- `crawl.py <ниша>`: собирает бизнесы с почтой или Telegram из каталога orgs.biz (зеркало групп ВК). Ниши внутри файла. Нужен `parse.py` рядом (в `../tools/`).
- `ov.py <запросы.json>`: свободные фото через Openverse (без обхода защит, только открытый API).
- `plan6.py`: кто, какая тема, тексты, позиции. Пишет `plan.json`.
- `batch6.py plan.json [slug...]`: создаёт `demos/_configs/<slug>.json`.
- `msgs6.py`: тексты писем и сообщений, `msgs6.json`.
- `qa.cjs slugs.json папка`: проверка демо на 360px (вылезания, битые картинки, ошибки).

Сборка демо: `node tools/make-demo.mjs demos/_configs/<slug>.json`, выкладка: `sh tools/publish-gh.sh`.
Правила: не больше 40 холодных писем в день, Telegram только вручную по таблице (аккаунт ловил PEER_FLOOD), обходить капчи и лимиты нельзя.
