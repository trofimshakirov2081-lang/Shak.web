# Рекламный ролик-визитка shak.web

Вертикальный 1080×1920, 30 fps, MP4 H.264, без озвучки.

## Концепция «Витрина»
- **Идея:** сайты показаны как витрина магазина, на которую смотришь сквозь стекло: живые страницы работ, глубина, движение камеры. Главное преимущество (админка) показано действием, а не списком.
- **Палитра:** тёплая бумага `#EFEAE2` и графит `#14110F` чередуются по сценам, один сигнальный цвет киноварь `#FF4D1A` для главных слов и действий, шалфей `#B9C4B1` для спокойных мест. Без неона и синего «IT».
- **Шрифты:** Sofia Sans Extra Condensed 900 (крупные слова капсом, «выезжают» из масок по буквам), Cormorant Garamond italic (эмоциональные слова: «Ваш сайт», «сами», «воплотим»), Ysabeau Office (мелкий текст).
- **Приёмы:** наклонная 3D-стена из живых страниц с параллаксом колонн и наводкой резкости; маски и раскрытие текста; живая запись админки внутри сцены; линия от кнопки «Опубликовать» к цене на сайте; наезд камеры на результат; плёночное зерно поверх кадра.
- **Музыка:** своя (генератор в `tools/video`), современный спокойный минимал 100-110 BPM, акценты синхронизированы со сменой сцен; короткие звуки на касаниях, раскрытии текста и публикации.

## Сцены (план 50-55 с)
1. Зацепка, 0-3,6 с: стена сайтов, «НЕ ШАБЛОН. Ваш сайт.» — готово (`scenes/s1-hook.html`).
2. Индивидуальный дизайн, 3,6-17 с: смена стилей крупными планами (цветы, кондитерская, барбершоп, кофейня, учебный центр, концепты с анимацией).
3. Админка, 17-33 с: цена меняется в настоящей админке и появляется на сайте — готово (`scenes/s3-admin.html`); ещё замена фото и смена оформления.
4. Польза для бизнеса, 33-45 с: путь клиента: открыл сайт, выбрал курс, оставил заявку, владельцу пришло сообщение.
5. Цена и призыв, 45-52 с — готово (`scenes/s5-final.html`).

## Как пересобрать
```
npm i                                   # GSAP
python3 -m http.server 8092             # в папке Shak.web, для снимков работ
node tools/capture.cjs                  # снимки работ в assets/sites
node tools/capture-admin.cjs            # запись админки (нужна тестовая копия АлтынНур на 8091)
node render.cjs s1-hook.html 3.6 render/preview/s1-hook.mp4 2.6   # сцена в MP4 + кадр-превью на 2,6 с
```
Каждая сцена: HTML + GSAP-таймлайн на паузе, `render.cjs` перематывает его покадрово (`window.seek(t)`) и снимает кадры, ffmpeg собирает MP4. Тайминги и элементы меняются в файле сцены.
